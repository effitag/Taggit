# Taggit

Share your moments

## Project Goals

Taggit aims to provide a simple platform for sharing short updates and attaching relevant tags. The project is at an early stage and will evolve as features are added.

## Setup

```bash
# Clone the repository
$ git clone <repository-url>
$ cd Taggit
```

## Build Steps

There is no compilation step at the moment. Open the files in the `assets` directory with your preferred web server or browser to preview the application.

## Version Control Guidelines

- Work on feature branches and keep `main` stable.
- Write clear commit messages in the present tense (e.g., "Add feature" instead of "Added feature").
- Keep commits focused on a single change or fix.

## Contribution Instructions

1. Fork this repository and create a new branch for your feature or fix.
2. Make your changes and commit following the version control guidelines.
3. Open a pull request describing the change and reference any related issues.
